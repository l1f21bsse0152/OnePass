# OnePass Presentation Demo Flow

## 1. Introduce the product

Describe OnePass as a platform connecting travelers with facilities through digital passes, wallet access, facility discovery, and QR-based check-in.

## 2. Show the traveler app

Walk through facility discovery, pass and wallet views, the QR scanning entry point, and monthly activity. Use a configured demo account and avoid displaying personal or secret information.

## 3. Show the web control center

Open the dashboard and select **Sample data** to demonstrate the administrator or facility workspace without changing live records. Highlight the dashboard views relevant to the selected role.

## 4. Close with the architecture

Summarize how the mobile app and web dashboard use the backend API, while the dashboard's sample-data routes remain isolated from live database records.

## Presentation-only notice

This walkthrough is a suggested presentation outline, not an automated test or a required application workflow.
