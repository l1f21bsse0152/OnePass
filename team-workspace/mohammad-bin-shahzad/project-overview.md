# OnePass Project Overview

OnePass brings traveler passes, facility discovery, and QR-based access together in one platform.

## Application areas

- **Mobile app:** A traveler-facing Expo and React Native app for account access, discovering facilities, viewing passes, managing a wallet, scanning facility QR codes, and reviewing activity.
- **Backend API:** An Express and MongoDB service for authentication, wallets, passes, facilities, QR access, and dashboard data.
- **Web dashboard:** A React and TypeScript control center with separate administrator and facility workspaces.

## Presentation boundary

This overview is presentation material only. Files in this folder are not imported by or required to run the OnePass application.
